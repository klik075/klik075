# 안녕하세요, 게임 개발자 정원우입니다 👋

> AI로 개발 방식이 빠르게 바뀌는 지금, 한 분야에 머물기보다 **기획부터 클라이언트·서버까지 게임 전체를 이해하는 개발자**가 더 필요해질 거라고 생각합니다.
> **재미있고 새로운 게임**을 만들기 위해, AI를 도구로 영역을 넓히되 설계와 판단은 직접 하는 **올라운더 게임 개발자**를 목표로 꾸준히 성장하고 있습니다.

- 🎮 **재미와 창의성**: 익숙한 장르에 새로운 규칙을 더하는 게임을 좋아합니다. 회사 경영에 좀비 디펜스를 합친 게임을 기획부터 혼자 만들었습니다.
- 🔭 **전체를 보는 시야**: 기능 하나보다 게임 전체 흐름을 먼저 보고, 진행·데이터·저장이 어떻게 맞물릴지 함께 설계합니다.
- 🏗 **구조와 안정성**: 반복 작업은 에디터 툴로 자동화하고, 서버가 판정하는 구조와 부하 테스트로 안정적인 서비스를 만들려고 노력합니다.
- 🤖 **AI 활용**: 구현 속도는 AI로 높이고, 구조를 어떻게 나눌지와 결과가 맞는지(테스트·부하 측정)는 직접 판단합니다.
- 🌱 **꾸준한 성장**: Unity 양성과정 → 인턴 → 1인 개발 → 백엔드 심화 과정 → 출시를 목표로 한 LAUNCH:ER까지, 한 단계씩 영역을 넓혀 가고 있습니다.
